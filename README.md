# 🤖 RG Game Bot (Telegram)

**RG Game Bot** — это многофункциональный Telegram-бот для игр и модерации чата, созданный для клана RG. 
Бот работает на Python (aiogram v3) и поддерживает игру «21» (Очко), а также команды модерации (мут, кик).

**RG Game Bot** is a multi-functional Telegram bot for games and chat moderation, created for the RG clan. 
Built with Python (aiogram v3), it supports the "21" (Blackjack) game and moderation commands.

---

## 🚀 Возможности / Features
- 🎲 **Игра 21 (Очко)**: Классическая карточная игра с инлайн-кнопками.
- 🔇 **Мут**: Ограничение прав пользователя (только для админов).
- 👢 **Кик**: Исключение пользователя из чата (только для админов).
- 📱 **Mobile Friendly**: Работает на любых устройствах.

## 🛠️ Технологии / Tech Stack
- **Python 3.10+**
- **Aiogram v3** (асинхронный фреймворк для Telegram)
- **GitHub** (для хранения кода)
- **Render** (для хостинга 24/7)
